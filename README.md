# Artem Ageev Production Portfolio

Готовый статический сайт-портфолио для GitHub Pages.

## Что внутри
- `index.html` — структура сайта
- `styles.css` — стили
- `script.js` — автозапуск видео
- `assets/hero.mp4` — видео для первого экрана
- `assets/*.svg` — временные логотипы клиентов

## Как опубликовать на GitHub Pages
1. Создай новый репозиторий.
2. Загрузи **содержимое этой папки** в корень репозитория.
3. Убедись, что `index.html` лежит в корне.
4. В `Settings -> Pages` выбери:
   - Branch: `main`
   - Folder: `/ (root)`
5. Сохрани и дождись публикации.

## Что заменить потом
- реальные логотипы клиентов
- тексты кейсов
- при желании превью/обложки к видео
