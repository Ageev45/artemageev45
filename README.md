# Artem Ageev Portfolio

Готовый статический сайт-портфолио без сборки и без зависимостей от фреймворков.
Подходит для загрузки в GitHub и публикации через GitHub Pages.

## Что внутри
- `index.html` — вся структура сайта
- `styles.css` — стили и адаптив
- `script.js` — мобильное меню и анимация появления блоков

## Как загрузить на GitHub
1. Создайте новый репозиторий.
2. Загрузите в него файлы из этой папки.
3. В настройках репозитория откройте Pages.
4. Выберите публикацию из ветки `main` и корня `/root`.
5. Сохраните — сайт опубликуется автоматически.

## Что желательно заменить перед запуском
- ссылку Telegram в блоке контактов
- email в блоке контактов
- тексты кейсов на реальные проекты
- при желании добавить превью-изображения, видео или шоурил

- адаптивный
- быстро грузится
- не требует сборки
- легко редактируется вручную
